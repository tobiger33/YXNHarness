# ANH Harness

An agent-neutral harness for building and validating visual UI and animation
changes in existing projects.

The project is intended to support local solo work first, with private,
branch-based collaboration and hosted previews as an optional mode. It should
work with the coding agent the project owner chooses rather than require a
specific model provider.

This repository is being initialized. Product architecture and implementation
will be developed here, separately from the Mascot Motion experiments.
